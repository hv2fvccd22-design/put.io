# Resume for put.io

A small static web app (installable PWA) for playing your put.io files and keeping your place across devices. It saves the playback position back to put.io, so the put.io web player and apps pick up where you stopped.

- Sign in with your own put.io app's client ID (OAuth), or paste an OAuth token.
- The token is stored only in your browser; there is no server.
- HLS playback uses [hls.js](https://github.com/video-dev/hls.js) 1.5.17.

No build step: the files in this repo are served as-is via GitHub Pages.
